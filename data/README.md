# Data workspace

## Synthetic decision case

Every customer and order in this repository is generated by `src/clv_decision_system/synthetic.py` with a fixed seed. The files do not contain production records, company identifiers, internal thresholds, or personal data.

## Generated tables

| Path | Grain | Purpose |
|---|---|---|
| `synthetic/customers.csv` | One row per synthetic customer | Acquisition context used at scoring time |
| `synthetic/orders.csv` | One row per synthetic order | Revenue, contribution margin, discount, category, channel, and return behavior |
| `processed/customer_snapshots.csv` | One row per customer and snapshot date | Leakage-safe features and 180-day outcomes used for temporal evaluation |

Run `python scripts/run_pipeline.py` to rebuild all three files and every committed report.

## Licensed public external validation

`data/external/` is a local-only workspace for UCI Online Retail II. The downloader,
canonical transaction file, quality report, and customer snapshots are reproducible,
but all row-level files are gitignored. Only aggregate outputs under
`reports/public_validation/` are eligible for publication.

| Local path | Grain | Publication rule |
|---|---|---|
| `external/raw/online-retail-ii.zip` | Official UCI archive | Never committed |
| `external/raw/online_retail_II.xlsx` | Source workbook | Never committed |
| `external/processed/transactions.csv.gz` | Canonical transaction line | Never committed |
| `external/processed/customer_snapshots.csv.gz` | Customer × snapshot | Never committed |
| `external/quality_report.json` | Aggregate data-quality counts | Regenerated locally; selected counts appear in committed metrics |

Run `make public-data`, `make public-snapshots`, and `make public-validate`. See the
[Public Data Card](../docs/PUBLIC_DATA_CARD.md) for provenance, CC BY 4.0 attribution,
field use, exclusions, and limitations.
